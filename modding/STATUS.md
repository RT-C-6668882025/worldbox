# 原生经济与社会系统开发版

本轮按缺口清单补充原生流程，保留原生窗口、地图操作、存档系统与 ARM64 基础包。当前源码在 PR #1，尚未合并或发布为正式版本。

## 最新结算与解锁规则

武器、护甲、饰品、装备词条和个人特质全部开放，不再受成就、探索或扩展添加的装备时代锁限制。原生装备制造仍扣金币和原材料；新增工业武器仍需实际工厂、零件和弹药。并未凭空给全体居民发装备，也不伪造成就完成记录。

所有发展支出仅使用金币，包括工资、建设、科研、军费、消费、贸易、产业投入、公共维护及国家拨款。取消 GOD 工资和所有自动兑换路径。GOD 只保留持有、估值、发行、回收、继承及用户主动兑换；仅持有 GOD 而没有金币，不能继续支付发展费用。

## 已接通的行为

- 城市、独立国家财政、个人均有金币/GOD 发行、回收和兑换。王国编辑器可切换独立国库与全国城市；村镇资源页操作本城；人物统计页点“个人双币”展开。数量与汇率可输入，保留常用档位。国家页拨款的城市目标为首都，村镇页为当前城，人物页可与所属城市转账。转账不增发。
- 个人 GOD 新增额度受五种实际工作能力影响；既有/继承财富不强制没收。五个成长方向在原生人物统计中显示等级、经验与下一阈值，并参与真实工作、制造、阅读、治理、装备耐久与发展。
- 实际工作工资不足记为个人欠薪，后续有资金时补发；不通过补发凭空造币。城市企业容量参与非农业岗位分配，实际加工雇用本城成年非军人；商业收入再投资形成工资预算和容量。农业自给保留，避免把原始社会设置成必须先有货币才能生存。
- 原生真实送货/加工计入产出，删除年度凭空生成产出并销毁原料的路径。基建和设施投资仍实际消耗资金和材料。
- 军饷按每年每个真实士兵结算，分批处理所有居民，每次至多 64 人，完成整城普查；不是每年只抽取 64 人。个人与年度标记避免重复发放，待处理年保存后可恢复。欠饷会降低幸福、连续缺饷可退伍。
- 国家独立财政按年从城市超出运行储备的结余收取 2%，优先帮助危机城市；未改写原生个人税与贡赋路径。公共维护有预算、有付款。长期欠薪、欠饷、公共服务与粮食不足形成社会压力，损害满意度、忠诚和基础设施，严重时调用原生建国/叛乱战争。持续失修会失去高级设施；补足资金和供给可恢复。
- 修正叛乱身份：原生叛乱的原政权是进攻方，新政权是防守方。叛军动员目标为成年人口 92%，受实际可征成年居民数量约束；不把儿童或在位君主强制改成士兵。实际岗位、征兵资格、超额退伍、出征使用统一目标，绕开原生 >15 成年人口和 70% 满编等待的阻断。
- 起事城市 ID 和规则版本写入战争存档，起事地区 <=5 人、灭亡或被夺回判负。旧版本误存的起事城市字段会迁移到当前叛军首都。攻占对方首都后迁都规则保留。
- 工业有燃料→钢材→机械→电力→元件→实验室/先进装备的消耗链，原生采掘/作坊建筑承载设施，雇用本城实际成人，资金不足不投产。工业库存可在实际城际补给与商船抵达事件交易，双方付款与货物同步变化。电力按年供给，不能无限囤积。
- 后期装备复用原生霰弹枪/能量武器表现，制造仍需个人货币、原生材料和工业零件；工业枪消耗弹药，能量武器消耗电力，攻击失败不扣弹。原料和实际生产设施约束制造，神力直接修改保留原生行为。
- 六类像素建筑外观用于已付费工业设施及逐年改造的住宅，保留原有尺寸、支点与碰撞，使用原生渲染和染色流程；不覆盖建设中、废墟与废弃建筑表现。
- 区分国库、城市公共余额、居民金币、待结收入和行业预算；人口金币汇总加法不会整数溢出变负。完整居民数值来自最近完成的年度普查。
- 原有加工、交易回滚、联盟财政与退出退款、家族继承、亲缘、亚种、原生世界法则适配保留。

## 模型边界

企业以城市行业容量、实际人员和共同商业资金建模，不是新增独立法律实体、股权交易所或逐企业编辑器。工业品与设施用原生自定义存档保存，在原生统计中展示，不伪称原 APK 已存在这些资源。新外观是六类程序化像素图，不是坦克、飞机和所有现代城市素材的完整资源包。原生航线、道路、寻路与宣战候选条件继续使用游戏机制。

资源、金币和原生等级解除的是已列出的玩法上限；整数表示、合法地图预设、碰撞、材料与资金检查仍保留。不是任意尺寸地图生成器。

## 验证

构建使用真实游戏 DLL。经济与适配器场景覆盖缺钱、恢复、欠薪补发、130 人军饷全覆盖、拨款守恒、十成人叛军岗位、产业投入、工业贸易、装备零件及弹药。离线渲染检查实际绘图函数的透明轮廓、六阶段区别、尺寸/支点、缓存、废墟/废弃回退及原生染色所需的 CPU 像素可读性。

准确检查数量和最终 APK/扩展 DLL 的 SHA-256 以 `build-receipt.json` 为准。签名 v1/v2/v3、整个 ZIP、嵌入程序集和安装对齐均需通过。没有 Android/Unity 实机运行环境，启动、真实存档、触屏输入、实机画面与性能尚待验收。

## 复现

```bash
python3 modding/build.py --apk /path/worldbox.apk --tools /path/tools --output /path/build --keystore /path/worldbox-test-signing.p12 --fetch-tools
```

必须使用已核验的原始 APK；不要把已修改的包再次作为输入。后续覆盖安装使用同一签名文件，签名密钥不进入仓库。
